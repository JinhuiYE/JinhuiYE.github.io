# Jinhui Ye 的个人学术主页

线上地址：<https://jhuiye.com/>。

`master` 是 GitHub Pages 发布分支，根目录存放生成后的静态页面；`.nojekyll` 使 Pages 直接发布这些文件。自定义域名由 `CNAME` 与现有 Pages 设置保留。

当前版本来自本地编辑工程提交 `9e2954e`。完整编辑工程使用 `content/posts/` 管理 Markdown、`data/` 管理结构化资料，并提供本地写作室与 Talks 管理；构建和导出后，将 `dist/` 的公开文件同步到这里。源稿、管理界面、临时文件和内部说明不上传到本仓库。

旧版完整保存在 [`backup/pre-redesign-2026-10-04`](https://github.com/JinhuiYE/JinhuiYE.github.io/tree/backup/pre-redesign-2026-10-04) 分支；原有历史未重写。原 `files/` 附件路径保留，常用旧页面提供跳转。

后续同步公开产物时保留 `CNAME`、`LICENSE`、`files/` 及旧链接跳转页，并随实际公开文章更新 `sitemap.xml`。使用普通提交与 push；不要 force push。

论文指标会通过 GitHub 和 Semantic Scholar 的公开接口更新；页面包含带日期的核实快照作为备用，避免限流时丢失已知数字。两类数据保持各自来源。
